Console

Grid Console reads and writes Casio G‑Shock settings over Web Bluetooth (Chrome / Edge). Each watch model is a profile; unknown watches drop into Diagnostic mode so their protocol can be captured and added. It never touches firmware and can't reskin a watch's LCD (that's fixed in ROM). Not affiliated with or endorsed by Casio. Protocol facts derived from the open-source Gadgetbridge project. “G‑SHOCK” is a trademark of Casio.
